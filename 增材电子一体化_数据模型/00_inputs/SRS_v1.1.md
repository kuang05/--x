## 0. 文档说明

### 0.1 目的

本文说明这款软件**要做成什么样**：有哪些功能、每个功能接受什么输入、产生什么结果、什么算合格。本文不规定代码结构、数据库表结构、接口实现方式；这些由开发团队自行设计。

### 0.2 术语

| 术语 | 含义 |
|---|---|
| 四域 | 结构、走线、切片、打印四个功能域 |
| STEP | 三维 CAD 交换格式；本软件唯一的三维几何输入 |
| 板文件 | 含器件、焊盘坐标、网络名的 PCB 设计文件（首版为 KiCad 板文件） |
| 网表 | 只含器件、引脚、网络连接关系，不含焊盘坐标 |
| MRC | 可打性规则检查（Manufacturability Rule Check） |
| 道次 | 一次材料沉积；同一高度可以有介电道次和银浆道次 |
| 物理层 | 下保护层、电路层、上保护层，共三层 |
| 版本 | 一次可追溯的工程状态；每次修改产生一个新版本 |
| Agent | 代替人执行设计/审查/裁决的智能体；只能做界面上能做的事 |
| 人工等效 | Agent 的每个操作，人都能在界面上手工复现 |
| 首版 | 本文覆盖的交付范围；真机联调不在首版 |

### 0.3 优先级

| 级别 | 含义 |
|---|---|
| P0 | 首版必须完成；缺失则不能交付 |
| P1 | 首版应完成；时间不足可降级，但要在验收时说明 |
| P2 | 首版可不做；为后续预留 |

### 0.4 需求编号

`模块-序号`：PRJ 工程与版本、STR 结构、CIR 走线、MRC 可打性、SLC 切片、PRT 打印、AGT 智能体、UI 界面、DAT 数据、NFR 非功能。编号一经使用不再复用。

## 1. 产品概述

### 1.1 问题与目标

传统 PCB 打样依赖蚀刻、曝光、电镀，周期长、门槛高；普通 3D 打印机只能打塑料，不懂电气连接。本产品把“电气设计”和“增材制造”接起来，回答一个两边都不回答的问题：

> **这块板，按这台机器、这套材料，到底打不打得出来？**

目标：用户导入三维结构和 PCB 板文件后，能在同一个软件里完成结构检查、器件放置与走线、可打性检查、双材料切片，导出可复现的 G-code；打印后把缺陷归因回设计与工艺。

### 1.2 产品定位

一款**桌面软件**，不是 EDA 的替代品，也不是 3D 打印切片器的替代品：

- 不做原理图、不做三维建模、不做多机调度；
- 只做“从已有设计到可打印路径”这一层，并把“打不打得出来”量化成规则和分数；
- 人和 Agent 共用同一套操作能力，Agent 不能绕过界面直接改数据。

### 1.3 用户与场景

| 用户 | 场景 | 最需要的能力 |
|---|---|---|
| 硬件创客、学生团队 | 没有 PCB 打样条件，想当天做出一块能焊的板 | 从 STEP 到 G-code 一条链，少切换工具 |
| 天线、射频小批量 | 曲面或异形基板，传统 PCB 做不了 | 立体走线、跨面、层间互连 |
| 教学、演示 | 要讲清“为什么这样打不出来” | 规则分数、违规解释、修改前后对比 |

### 1.4 产品边界

**做：**

- STEP 导入、几何检查、三维查看、面分析、布尔建议；
- 板文件导入、器件放置、手动/自动布线、跳线、连通性检查；
- 可打性规则检查、评分、解释、修改建议；
- 三层双材料切片、路径预览、时间/材料估算、G-code 导出；
- 设备连接、虚拟打印、暂停/恢复、故障处理、缺陷记录与归因；
- 版本历史、撤销/重做、工程导出；
- 设计、审查、裁决三类 Agent 能力与人工确认。

**不做：**

- 原理图编辑器、三维建模、装配约束；
- STL 输入、网格布尔；
- 多色/多材料之外的打印管理、模型库、手机端；
- 多机调度、远程运维、社区、固件 OTA；
- 首版的真机联调（只做虚拟打印与接口预留）。

### 1.5 运行环境

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 64 位 |
| 内存 | 建议 8 GB 以上 |
| 显卡 | 集成显卡可运行；独立显卡更佳 |
| 分辨率 | 1920×1080 及以上 |
| 网络 | 核心功能离线可用；云端智能体为可选 |
| 数据位置 | 本机数据目录；默认不上传 |
| 基准机器 | 见文档头；低于此配置允许降低显示精度，但不作为验收环境 |

### 1.6 约束与假设

1. 三维几何只接受 STEP；不接收 STL，不做网格布尔。
2. 首版幅面 200 × 200 mm；400 × 400 mm 为可选配置，不写死。
3. 首版材料为可焊银浆（A）与热固化介电环氧（B）；**不使用 UV**。
4. 电气输入以含焊盘坐标的板文件为主；纯网表缺少焊盘坐标，只能做连通性检查，不能直接布线。
5. 首版用虚拟打印机演示；真机接口需预留，但不在首版验收。
6. 软件面向单用户、单工程、单设备；不做多人协同。
7. 首版不承诺任意 ECAD 格式、任意 Gerber 方言、双层过孔、连续曲面切片。

### 1.7 首版工艺与硬件基线

| 项 | 基线 |
|---|---|
| 幅面 | 200 × 200 mm（400 × 400 可选） |

| 加热 | 热台 350 W、烘箱 300 W；两路测温 + 一路独立超温切断 |
| 急停 | 独立硬件急停，切断加热与出料，保留记录 |
| 材料 A | 可焊烧结银浆 |

| 总厚 | 目标 0.35–0.40 mm（层厚相加为 0.44 mm，见待确认事项） |
| 线宽 / 间距 | 0.6 mm / 0.6 mm |
| 槽深 | 0.10 mm |
| 焊盘 | 1.5 × 1.0 mm |
| 双喷头对位 | ≤ 0.1 mm（热态标定） |
| 焊盘与保护层高差 | ≤ 0.05 mm |
| 预凝胶 | 80 ℃，1–2 min |

| 层固化 | 170 ℃，6–8 min；升温 ≤ 3 ℃/min |

| 道次 | 典型 7 个；银浆分两次填则 8 个 |

## 2. 总体功能

### 2.1 功能结构

| 模块 | 必须提供的功能 |
|---|---|
| 工程与版本 | 新建/打开/保存、导入、版本历史、撤销/重做、工程包 |
| 结构域 | STEP 导入与检查、三维查看、面分析、布尔建议、特征列表 |
| 走线域 | 板文件导入、器件放置、手动/自动布线、跳线、连通性 |
| 可打性 | 七条规则、评分、问题列表、解释、建议、热力图 |
| 切片 | 三层双材料、道次规划、路径生成、排程、预览、G-code、估算 |
| 打印 | 连接设备、开始/暂停/恢复/停止、虚拟打印、故障、缺陷 |
| 智能体 | 设计、审查、裁决、计划、对比卡片、三级授权、重放 |
| 界面 | 三维/二维画布、属性面板、问题面板、计划/对比、对话、打印面板 |
| 数据 | 工程数据、版本、文件、导入导出、完整性、迁移 |

### 2.2 典型流程

**流程 A：从结构到分数**

1. 新建工程，导入 STEP；
2. 查看三维模型，检查几何诊断；
3. 查看面分析结果，接受或拒绝布尔建议；
4. 导入板文件，放置器件，手动或自动布线；
5. 运行可打性检查，查看分数与问题列表。

**流程 B：从分数到 G-code**

1. 选择工艺配置（三层、双材料、固化曲线）；
2. 切片，逐层/逐道次预览；
3. 检查切片后的连通性；
4. 导出 G-code，记录哈希；
5. 用虚拟打印机回放，确认路径与时间。

**流程 C：从缺陷回到设计**

1. 虚拟打印注入故障，生成缺陷记录；
2. 缺陷定位到层、位置、类型；
3. 归因到某个版本；
4. 回滚或重新切片；
5. 重放确认 G-code 哈希一致。

**流程 D：Agent 辅助**

1. 运行可打性检查，得到初始分；
2. 设计 Agent 给出修改计划；
3. 审查 Agent 复核计划；
4. 用户查看对比卡片，选择“应用/拒绝/只应用一步”；
5. 收敛后保存版本与计划，供重放。

### 2.3 角色

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 用户 | 所有界面操作、确认/拒绝 Agent 建议、控制打印 | 绕过界面直接改数据 |
| 设计 Agent | 提出结构/走线修改并执行经授权的步骤 | 改网络拓扑、跳过检查、直接写数据 |
| 审查 Agent | 只读检查、解释、评分 | 发起任何修改 |
| 裁决 Agent | 在多个方案间选择、决定停止/回退 | 绕过授权直接执行 |

## 3. 功能需求

### 3.1 工程与版本

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| PRJ-001 | 新建工程：输入名称、单位（默认 mm）、幅面（默认 200×200 mm），生成空工程与初始版本。 | P0 | 新建后画布为空、版本为 0、可直接导入 STEP。 |
| PRJ-002 | 打开工程：显示最近工程列表；打开后恢复到最新版本；快照缺失时能从历史重建。 | P0 | 关闭再打开，模型、走线、分数与关闭前一致。 |
| PRJ-003 | 自动保存与恢复：每次有效修改后自动保存；异常退出后再次打开给出恢复提示。 | P0 | 强制结束进程后重开，能恢复到最近一次成功版本。 |
| PRJ-004 | 版本历史：按时间列出每次修改的作者、原因、修改前后分数；可查看修改内容。 | P0 | 任选两个版本，能看出改了哪些对象、分数变化多少。 |
| PRJ-005 | 撤销/重做：会话内操作栈，至少 20 步；**撤销不产生版本**，只在保存/提交时产生新版本；撤销动作记入操作日志。 | P0 | 连续撤销 10 步再重做 10 步，状态与操作前一致；版本号在撤销过程中不变。 |
| PRJ-006 | 工程包导出/导入：导出一个文件包含工程元数据、版本历史、模型与路径引用；可在另一台机器导入。 | P1 | 导出后删除本工程，再导入，版本与分数一致。 |
| PRJ-007 | 工程复制、重命名、删除：删除需二次确认；删除后可从回收站恢复。 | P1 | 复制后的工程与原工程互不影响。 |
| PRJ-008 | 单位与坐标：全软件统一 mm；板坐标原点在板框左下角；允许导入 inch 并换算。 | P0 | 导入 inch 文件后，尺寸与 mm 标注一致。 |
| PRJ-009 | 软件设置：默认单位、自动保存间隔、云功能开关、数据目录、日志级别；修改后持久化。 | P1 | 重启后设置仍生效；关闭云功能后不再发起云端请求。 |

### 3.2 结构域

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| STR-001 | STEP 导入：支持 AP203/214/242、单实体与装配体；装配体展平；记录文件哈希。 | P0 | 20 MB 以内文件 15 s 内完成导入并显示。 |
| STR-002 | 几何检查：识别缺面、自交、极小面、缝合失败、单位缺失；给出诊断码与处理建议；不静默修补。 | P0 | 20 个破损样本全部“不崩溃、有诊断码”。 |
| STR-003 | 三维查看：旋转、缩放、平移、适配窗口、剖切、测量；显示板框、特征、器件。 | P0 | 基准机器上 20 万三角面 ≥30 fps；50 万面允许自动降精度显示，帧率不低于 20 fps。 |
| STR-004 | 面分析：区分平面、柱面、其他；显示法向、面积、位置；标记不利于打印的面。 | P0 | 选一个面，能看到类型、法向、面积与可打性提示。 |
| STR-005 | 布尔建议：支持方块、圆柱、棱柱的加/减体候选；给出参数与预览，**首版只预览不执行**；执行与重建为 V1。 | P0 | 预览可开关、参数可调、可拒绝；拒绝后模型与分数不变。 |
| STR-006 | 特征列表：记录已接受与待接受的特征；启用/停用、排序、删除；执行重建为 V1。 | P1 | 列表操作不改变模型；标记为“待执行”时切片给出提示。 |
| STR-007 | 板框：自动识别最大闭合轮廓；识别失败允许手动画矩形/多边形；无板框时明确提示。 | P0 | 无板框的模型不能进入切片，提示原因。 |
| STR-008 | 网格化：容差可调（默认 0.02 mm）；显示与切片使用同一份网格；大模型可降精度。 | P0 | 容差从 0.02 改到 0.05，面数下降、显示不明显失真。 |
| STR-009 | 失败回滚：布尔或重建失败时，保留上一个可用模型与版本，不清空工程。 | P0 | 制造一次共面失败，工程仍可查看与回滚。 |

### 3.3 走线域

| 编号 | 需求 | 优先级 | 验收要点 |
|---|---|---|---|
| CIR-001 | 板文件导入：读取器件、焊盘坐标、网络名、板框；支持 KiCad 板文件；纯网表需配坐标表。 | P0 | 导入后有器件、焊盘、飞线；数量与源文件一致。 |
| CIR-002 | 器件放置：移动、旋转 0/90/180/270、翻面、锁定；支持栅格吸附与对齐。 | P0 | 移动后飞线更新；锁定器件不能移动。 |
| CIR-003 | 网络显示：显示飞线、焊盘编号、网络名；可高亮单个网络。 | P0 | 点一个网络，仅该网络的飞线与焊盘高亮。 |
| CIR-004 | 手动走线：**首版在二维俯视/展开视图布线**，设置线宽与所在面；三维视图只做显示与校验；支持拖拽改道、删除、重画。三维内直接画线为 V1。 | P0 | 二维画一条线后连通性通过，三维显示一致；撤销后恢复。 |
| CIR-005 | 自动布局：给出若干器件摆放候选，按可打性/连线长度排序；用户选择后应用。 | P1 | 应用候选后飞线总长度下降，可撤销。 |
| CIR-006 | 自动布线：对单个网络在单层内布线，避开焊盘、已布线和禁布区；失败给出原因。 | P1 | 两焊盘简单网络能布通；被挡住时说明被谁挡住。 |
| CIR-007 | 跳线：支持在同一网络的两个焊盘之间加 0Ω 跳线；可删除；可给出候选。 | P1 | 加跳线后连通性通过；候选可预览，不自动应用。 |
| CIR-008 | 跨面与层间：首版至少支持顶面/底面走线；跨面与层间互连可后置，但数据结构要预留层号。 | P1 | 切到另一面，走线仍可见且连通性正确。 |
| CIR-009 | 连通性检查：每个网络是否连通；不同网络是否短路；失败位置可定位。 | P0 | 人为断开一条线，检查报“断路”；两条线相交，报“短路”。 |
| CIR-010 | 约束修改：改线宽、网络类、封装；修改前显示影响范围；不满足工艺下限时拒绝。 | P0 | 线宽改到 0.3 mm 被拒绝，并说明下限。 |
| CIR-011 | 走线合法性：禁止零长度、重复点、越出板框；非法输入给出具体原因。 | P0 | 越界点无法落线，提示“超出板框”。 |

## 4. 数据需求

### 4.1 实体

| 实体 | 说明 | 关键关系 |
|---|---|---|
| 工程 | 一个项目的根 | 包含结构、电路、切片、版本 |
| 会话 | 一次打开/编辑过程 | 关联工程与起始版本 |
| 版本 | 一次可追溯的修改 | 有父版本；关联分数与作者 |
| 计划 | Agent 的执行计划 | 关联工程；步骤可回放 |
| 结构 | STEP 模型与特征树 | 属于工程；包含特征 |
| 特征 | 一次加/减体 | 属于结构 |
| 电路 | 板文件导入结果 | 属于工程；包含器件/网络/走线 |
| 器件 | 元件封装与位置 | 属于电路；包含焊盘 |
| 焊盘 | 器件与网络的连接点 | 属于器件；可属于网络 |
| 网络 | 电气连接 | 属于电路；包含焊盘/走线/跳线 |
| 走线 | 一条三维路径 | 属于网络 |
| 跳线 | 两个焊盘之间的 0Ω 连接 | 属于网络 |
| 切片 | 一次切片结果 | 绑定设计版本；包含层/道次 |
| 工艺参数 | 层高、速度、温度等 | 关联材料；属于切片 |
| 材料 | 银浆或介电配方 | 被参数/层引用 |
| 层/道次 | 一次材料沉积 | 属于切片；包含路径 |
| 路径 | 一段可执行轨迹 | 属于层/道次 |
| 打印作业 | 一次打印 | 关联切片与设备；包含缺陷 |
| 设备 | 真机或虚拟打印机 | 执行作业 |
| 缺陷 | 打印中发现的问题 | 属于作业；可归因到版本 |
| 规则 | 可打性规则与阈值 | 产生问题 |
| 规则版本 | 一组规则的快照（阈值、启用状态、生效时间） | 属于规则；问题与历史分数引用某个规则版本 |
| 工具几何 | 针头内径、针尖外形、安全间隙、喷头包络 | 被可达性/遮挡规则引用；可随喷嘴更换 |
| 材料批次 | 材料型号 + 批次号 + 到货日期 + 启用状态 | 被切片与 G-code 引用；缺陷可回溯到批次 |
| 问题 | 一条违规 | 关联规则与版本 |

### 4.2 数据规则

1. 一个工程同时只有一个“当前版本”；历史版本只读。
2. 切片必须绑定一个设计版本；设计变更后切片标记为过期。
3. 打印作业必须绑定一个切片版本；缺陷必须能追溯到作业。
4. 删除工程/版本需二次确认；历史默认不物理删除。
5. 大文件（STEP、网格、路径、证据）按内容哈希存储，避免重复。
6. 数据目录可备份、可迁移；不依赖云端。

### 7.1 验收任务

| 编号 | 域 | 输入 | 期望结果 | 通过标准 |
|---|---|---|---|---|
| T01 | 结构 | 单实体 STEP | 导入、显示、面数/包围盒正确 | 15 s 内完成，无错误 |

| T03 | 结构 | 平板 + 加凸台建议 | 预览参数可调、可拒绝 | 预览正确，拒绝后模型不变（执行布尔为 V1 验收） |

| T06 | 走线 | 10 器件板文件 | 器件、焊盘、飞线显示 | 数量与源文件一致 |

| T10 | MRC | 细线/近距 | 命中 R1/R2 | 分数下降，问题可定位 |
| T11 | MRC | 带侧壁与凸台的 STEP（含 60° 悬垂面与遮挡） | 命中 R3/R4/R5 | 每条问题有对象与原因 |
| T12 | MRC | 温度场/流道 | 命中 R6/R7 | 阈值可配置 |
| T13 | 切片 | 三层板 | 3 个物理层、7 个道次 | 层序/厚度正确 |

| T17 | 打印 | 虚拟打印 | 进度、层号、时间正确 | 回放完成 |
| T18 | 打印 | 注入断线 | 生成缺陷并归因 | 层/位置正确 |
| T19 | 智能体 | 固定验收板 T19-A（8 器件、12 网络、单层、初始 62±3 分，文件哈希随本文入库） | 提升 ≥15 分，轮数 ≤8 | 对比卡片可应用，分数提升可复现 |
| T20 | 全链 | 导入→切片→打印 | 全链通过，重放一致 | 哈希一致，无崩溃 |

### 7.2 验收口径

- P0 任务全部通过；P1 任务允许失败，但必须给出诊断码与原因；
- T19 使用固定验收板 T19-A（8 器件、12 网络、单层、初始 62±3 分），输入文件与哈希随本文入库；换板视为不同任务；
- T20 全链必须通过：导入 → 面判定 → 打分 → 切片 → G-code → 虚拟回放；
- 每个任务输出结果记录：成功/失败、轮数、耗时、初始分、收敛分、G-code 哈希；
- 失败任务必须给出诊断码与原因，不允许崩溃或静默跳过；
- 人工等效抽检：随机 5 条 Agent 操作，人工在界面复现，≥80% 通过。
