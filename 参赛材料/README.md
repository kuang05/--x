## 三分钟看懂

1. **做的事**：把"这块增材电路能不能打出来"变成可计算、可解释、可复放的判断。
2. **凭什么**：五维评审逐条有证据——61 个端到端用例、T01–T25 验收 25/25、Agent 62→97 分 4 轮收敛、59 表数据模型 41 项校验、PostgreSQL 实跑 PASS。
3. **AI 在哪**：可解释的工艺决策智能体；决策走规则引擎（可验收），LLM 用于解释与建议排序，断网可降级。

## 一键跑通（现场用）

```bash
cd 增材电子一体化_软件
python3 -m aepcb.cli doctor      # 环境自检 8/8
python3 -m aepcb.cli pitch       # 清库 → 全链验收 → 报告 + 证据包
# 产物：workspace/report.html、workspace/evidence.md
```

指定工作目录：`python3 -m aepcb.cli --workspace /tmp/demo pitch`
