## 3. 复跑命令

```bash
cd 增材电子一体化_软件

# 一键：清库 → 25 项验收 → 报告 + 证据包（约 45 s）
python3 -m aepcb.cli pitch

# 分项
python3 -m unittest discover -s tests     # 62 个端到端用例
python3 -m aepcb.cli accept               # T01–T25，P0 失败退出码 1
python3 -m aepcb.cli accept --list        # 只列 25 项与级别
python3 tools/bench.py                    # 切片基准（中位数 + 区间）
python3 tools/ui_bench.py --repeat 5      # UI 性能（中位数 ± MAD）
python3 tools/check_deps.py               # import 与 pyproject 一致性
python3 tools/pg_verify.py                # PostgreSQL 实跑（需 pgserver）
python3 -m aepcb.cli doctor               # 环境自检
python3 -m aepcb.cli serve                # 界面 http://127.0.0.1:8765
```

`make demo / test / accept / bench / pg / ci / pitch` 为等价入口。
