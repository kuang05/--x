# 演示视频分镜（5:00 版 / 3:00 精简版）

> 用途：直接照着录。每镜给「画面 / 操作 / 字幕 / 旁白 / 时长」。
> 原则：**每个结论后面跟着一条当场能跑的命令**，不出现"我们实现了"这种空话。

## 录制准备

| 项 | 设置 |
|---|---|
| 分辨率 | 1920×1080，窗口最大化 |
| 字体 | 终端 16 pt，浏览器 110% 缩放 |
| 主题 | 深色（与软件界面一致，避免闪烁） |
| 鼠标 | 显示点击高亮（OBS 或系统设置） |
| 提前跑一遍 | `aepcb doctor` 确保 11/11，避免现场等依赖 |
| 清库 | 录制前删 `workspace/app.db`，让演示从零开始 |

---

## 镜头表（5 分钟版）

### 镜 1｜片头（0:00–0:15）

- **画面**：软件 3D 视图静帧（板面 + 走线 + 器件），缓慢旋转
- **操作**：无（录屏回放）
- **字幕**：增材电子一体化软件 —— 把"能不能打出来"变成可计算的判断
- **旁白**：这块板子不是画出来的，是算出来能打的。
- **时长**：15 s

### 镜 2｜问题（0:15–0:45）

- **画面**：左右对比图（传统打样 3–7 天 vs 直接打印当日）
- **操作**：无（图文）
- **字幕**：EDA 管电气正确，切片管路径，没人管"能不能造"
- **旁白**：增材电子跳过了开板，但设计软件和切片软件之间有个断点。
- **时长**：30 s

### 镜 3｜环境自检 + 一键全链（0:45–1:35）

- **画面**：终端
- **操作**：
  ```bash
  python3 -m aepcb.cli doctor      # 11/11
  python3 -m aepcb.cli demo        # 全链
  ```
- **字幕**：一条命令：导入 → 布线 → 评分 → 切片 → G-code → 虚拟打印 → 智能体
- **旁白**：全链跑一遍，十几秒。注意最后一行，分数从 62 到 97。
- **时长**：50 s（demo 输出可 2× 加速）

### 镜 4｜可打性评分（1:35–2:25）

- **画面**：终端 + 右侧问题列表
- **操作**：
  ```bash
  python3 -m aepcb.cli check
  ```
  然后指出 6 条问题：R1×3、R2、R6、R7，每条带实测值/阈值
- **字幕**：62 分 = 100 − Σ 严重度，每条问题都能追到实测值
- **旁白**：不是给一个分数，是给一张能查的账单。
- **时长**：50 s

### 镜 5｜界面操作（2:25–3:15）

- **画面**：浏览器（`aepcb serve`）
- **操作**（连续四个动作，每个 10 s）：
  1. 切 3D，拖拽旋转、滚轮缩放、双击复位
  2. 拉剖切滑块，层 0 消失、层 1 保留
  3. 2D 里拖拽走线中间拐点改道
  4. 选中器件 → 旋转 90° → 观察焊盘跟着转
- **字幕**：3D 旋转 · 剖切 · 两点测距 · 拖拽改道 · 器件编辑
- **旁白**：这些不是截图，是能改设计的界面。
- **时长**：50 s

### 镜 6｜智能体（3:15–4:00）

- **画面**：终端 + 对比卡片
- **操作**：
  ```bash
  python3 -m aepcb.cli agent
  ```
  展示 4 轮、每轮的分对比、最终 97 分；再打开重放，分数一致
- **字幕**：每步存绝对几何，重放不重新推理
- **旁白**：它不是在"猜"，每一步都能回放。
- **时长**：45 s

### 镜 7｜验收与证据（4:00–4:35）

- **画面**：终端 + `evidence.md`
- **操作**：
  ```bash
  python3 -m aepcb.cli accept     # 25/25
  ```
  打开 `workspace/evidence.md`，快速滚动 8 节
- **字幕**：T01–T25（P0 20 项）· 8 节证据包 · 一条命令复跑
- **旁白**：所有数字都在这个文件里，现场可以重跑。
- **时长**：35 s

### 镜 8｜收尾（4:35–5:00）

- **画面**：性能表格 + 边界表 + 仓库地址
- **操作**：无（图文）
- **字幕**：切片 0.46 s · 评分 3.0 ms · 单测 71/71 · 覆盖率 69.2%
- **旁白**：边界也写在里面——没接真机、三维帧率只测了投影。我们不藏。
- **时长**：25 s

## 后期要点

| 项 | 做法 |
|---|---|
| 字幕 | 全部旁白上硬字幕（评委常静音看） |
| 加速 | `demo` 与 `accept` 的等待段 2×–4×，但**分数出现的那一帧要原速** |
| 高亮 | 每次输出分数时加红框/放大 1.5 s |
| 鼠标 | 点击处加 0.5 s 圆环动画 |
| 音乐 | 无（技术演示不需要），只留旁白 |
| 结尾 | 定格 3 s，放仓库地址与"可现场复跑" |

## 录制检查清单

- [ ] 录制前删库，确保 `demo` 从零开始
- [ ] `doctor` 全绿，避免录到缺依赖
- [ ] 终端字号够大（1080p 下 16 pt 起）
- [ ] 不在录屏中出现绝对路径 `/workspace/data/sessions/...`（用 `cd 软件` 代替）
- [ ] 不出现真实姓名/学校（除非已确认可公开）
- [ ] 核对片中数字与 `workspace/evidence.md` 一致

## 不要做的事

| 做法 | 为什么不行 |
|---|---|
| 把 3D 投影帧率说成"浏览器 30 fps" | 口径不同，评委一问就穿 |
| 说"支持 STEP 完整 B-rep" | 只支持子集 + 告警 |
| 用剪辑掩盖长等待 | 现场演示会对不上 |
| 出现"我们的 AI 很智能" | 没有指标支撑，改说"规则负责可验收，LLM 负责解释" |
