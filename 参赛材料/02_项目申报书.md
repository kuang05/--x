# 项目申报书 · 增材电子一体化软件（Additive-EDA）

> 参赛赛道：华为 ICT 大赛 · 创新赛
> 建议赛题方向：**Agent 智能体设计与应用**（备选：AI 创新应用）
> 定位一句话：**让"能不能打印出来"变成可计算、可解释、可复放的工艺决策。**

## 1. 问题与场景

增材电子（把导电银浆与介电材料直接打印成电路）正在把 PCB 打样从"开板—蚀刻—贴片"变成"设计完就能打"。但工程链条上有个断点：

- 传统 EDA 只关心**电气正确**（连通、间距、DRC），不关心**能不能造出来**；
- 切片软件只关心**路径**，不理解**网络、焊盘、层间互连**；
- 两者的判断依据散落在人脑与经验里，换一台设备、换一批材料，结论就变。

结果：设计改一版、打一版、坏一版，打样周期与银浆浪费都不可控。

## 2. 方案总览

四域闭环，一个数据模型贯穿：

```
结构(STEP) ─┐
            ├─→ 可打性评分(R1–R7) ─→ 切片(3层7道次) ─→ G-code(双哈希) ─→ 虚拟打印 ─→ 缺陷归因
走线(KiCad) ─┘         ↑                                     │
                      └──────── Agent 决策回路（可重放）←──────┘
```

- **结构域**：STEP 子集解析（点/平面/圆柱面/单位/包围盒），圆柱面参与悬垂判定。
- **走线域**：器件/焊盘/网络/走线/过孔/跳线/禁布区；连通性用并查集，**跨层只认过孔**。
- **可打性域**：R1 线宽、R2 间距、R3 悬垂、R4 可达、R5 遮挡、R6 温度、R7 介电流道；评分带规则版本。
- **切片与打印域**：3 层 7 道次，轮廓 + 内填 + 空移排序 + 层间正交；G-code 双哈希；虚拟打印回放、故障注入、缺陷归因。

## 3. 创新点（每条都可复跑）

| # | 创新点 | 为什么不是"常规做法" | 复跑方式 |
|---|---|---|---|
| 1 | **可解释评分**：分数 = 100 − Σ 严重度权重，每条问题带实测值/阈值/建议；阈值属规则版本，改阈值不覆盖旧分 | 常见做法是"一个分数"，无法回答"为什么 62 分" | `aepcb check` + `mrc_run/mrc_issue` |
| 2 | **可重放智能体**：步骤存**修改后的绝对状态**，重放回放 `tool_call` 而不重新推理 | LLM 决策不可复现，验收无法举证 | `aepcb agent` → 重放分数一致 |
| 3 | **双哈希证据链**：`content_hash`（规范化）与 `file_hash`（字节）分离，重复导出幂等 | 只存文件哈希会让"两次导出一致"永远为假 | `aepcb export` 连跑两次 |
| 4 | **数据模型单一事实源**：Python DSL → DDL/字典/ER/追溯矩阵四份产物 | 文档与库结构必然漂移 | `tools/gen_*.py` + 41 项模型校验 |
| 5 | **过孔即跨层唯一通路**：连通性判定不允许"坐标重合就算通" | 图形上连了、电学上没连，是最难查的错 | `test_22`：无孔 fail → 加孔 pass |

## 4. 智能体设计（对应"必选 AI"）

**定位**：可解释、可重放的工艺决策智能体；LLM 负责"解释与建议排序"，规则引擎负责"可验收的决策"。

- **计划**：目标（分数 ≥95）、约束（禁改网络拓扑）、基线版本、授权级别（默认逐步确认）。
- **步骤**：`route.set_width` / `route.set_points`，只允许界面等价操作；每步存前置条件、期望、绝对状态。
- **裁决**：对比卡片给出分数变化、改动对象、理由；支持"应用 / 拒绝 / 只应用一步"。
- **重放**：七要素固定（起始版本+摘要、工具链版本、规则版本、工具几何、工艺配置+哈希、材料批次、随机种子），回放不重新推理。
- **降级**：断网时用本地规则集跑通"检查—修改—复检"，`plan.degraded=1` 留痕。

**为什么规则优先**：验收要的是"同一输入同一输出"。LLM 用于把规则结论翻译成人话、给多条建议排序；一旦让它直接改几何，"可验收"就不成立。

## 6. 商业价值与社会效益

| 指标 | 传统打样 | 本方案 | 说明 |
|---|---|---|---|
| 首次可打印率 | 依赖工程师经验 | 规则前置拦截（R1–R7） | 减少"打完才发现不能打" |
| 改版轮次 | 2–4 轮 | Agent 4 轮内收敛到 97 分 | 每轮有对比卡片可审计 |
| 打样周期 | 3–7 天（外发） | 当日（本地打印） | 取决于设备，方案侧只保证"设计到 G-code" |
| 材料浪费 | 试错消耗银浆 | 切片前拦截 + 估算用量 | 估算含路径长/时间/材料 |

**社会效益**：高校实验室与中小团队以低成本获得"可解释的工艺判断"；规则版本化让产线换型有据可查。
**国产化**：全栈 Python 自研、无商业 EDA 依赖；云端接口预留（可对接华为云 ModelArts/盘古做解释与建议排序，属规划项，不在当前验收范围）。

## 8. 边界与风险（主动说明，答辩加分）

1. **无真机**：Marlin 协议已实现并用假固件验证，未接物理打印机。
2. **STEP 为子集**：不做 B-rep 布尔与曲面重建。
3. **KiCad 为子集**：单层贴片 + F.Cu/In{n}.Cu/B.Cu 线段 + 简单过孔；盲埋孔层对保留但不做孔壁工艺建模。
4. **LLM 不在关键路径**：当前决策由规则引擎给出，LLM 仅用于解释与排序（可关闭）。
5. **性能为单机数据**：Intel Xeon Platinum 8255C @2.5 GHz / 3 核（非 SRS 指定的 i5-12400）；本文性能数字均按此机器记录。
